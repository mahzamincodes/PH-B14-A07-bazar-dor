# বাজার দর (BazarDor) 🛒

BazarDor is a responsive online grocery platform that allows users to explore grocery products, browse products by category, view product details, and securely sign in or register. It provides a simple and user-friendly experience for discovering everyday grocery products.

## 🌐 Live Website

[Visit BazarDor](https://ph-b14-a07-bazar-dor.vercel.app/)

![BazarDor Homepage](./ph-b14-a07-bazar-dor.vercel.app_%20(1).png)

## ✨ Key Features

1. **Responsive Design:** Provides a smooth browsing experience on mobile, tablet, and desktop devices.
2. **Product Browsing:** Allows users to explore grocery products on the homepage.
3. **Category Navigation:** Enables users to browse products by different categories.
4. **Product Details:** Displays detailed information about individual products.
5. **User Authentication:** Supports registration and login using email and password, Google, and GitHub.
6. **Secure Authentication:** Uses Better Auth to manage user authentication.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mahzamincodes/PH-B14-A07-bazar-dor.git
cd PH-B14-A07-bazar-dor
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the project root and configure the required Better Auth, MongoDB, and other environment variables.

### 4. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
